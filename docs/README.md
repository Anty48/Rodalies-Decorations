# Rodalies Decorations — Wiki

Mod de Minecraft **Forge 1.20.1** con bloques decorativos temáticos de Rodalies/Renfe:
señales ferroviarias editables, carteles de estación, el parabrisas del tren 447 y logos.

## Índice

- **[Crafteos](Crafteos.md)** — cómo se fabrica cada bloque (el nuevo sistema de *base + tintes*).
- **[Acumular señales](Acumular-senales.md)** — señales de velocidad dobles/triples y la combinada con fin de LTV.

## Bloques de señalización

| Señal | Texto editable | Versión short |
|---|---|---|
| Señal de velocidad | Sí (1–3 dígitos) | Sí |
| LTV (Limitación Temporal de Velocidad) | Sí | Sí |
| Fin de LTV | No | Sí |
| Cartel de señales | Sí (2 líneas) | Sí |
| Señal de apeadero | No | Sí |
| Señal de silbato | No | Sí |
| Señal de detención inmediata | No | Sí |
| Cartel de número de vía | Sí | — |
| Cartel de estación (Rodalies / genérico) | Sí | — |
| **Base** (pieza de crafteo) | — | — |

> Las señales tienen dos alturas: **normal** (poste alto, 3 celdas) y **short** (poste corto, 2 celdas).
> La *short* se coloca directamente a la altura de la señal; la *normal* añade una celda más de poste abajo.

## Interacción

- **Clic derecho** sobre una señal editable → abre la pantalla para escribir su texto.
- **El texto es siempre legible** (retroiluminado) y se orienta según la dirección de la señal.
