# Rodalies Decorations

**Rodalies Decorations** es un mod de decoración para **Minecraft 1.20.1 (Forge)** que añade
bloques de ambientación ferroviaria inspirados en Rodalies y Renfe: señales de vía editables,
carteles de estación, logotipos corporativos, el parabrisas del tren de la serie 447 y una
puerta corredera de tren.

El mod está pensado para la construcción de estaciones, andenes y material rodante. No modifica
la jugabilidad ni añade mecánicas de mundo; todos sus elementos son decorativos, con algunas
interacciones de configuración (texto editable, apilado de señales y apertura de puertas).

## Resumen de contenidos

| Categoría | Elementos |
|---|---|
| Logotipos | Logo R de Rodalies, Logo Renfe, Logo de Cercanías, Cuarzo con línea púrpura (cada uno con su variante de una cara) |
| Material rodante | Parabrisas del tren 447, puerta corredera de tren (apertura hacia delante o hacia atrás) |
| Carteles de estación | Señal de estación de Rodalies, señal de estación genérica, cartel de número de vía |
| Señalización de vía | Velocidad, LTV y Fin de LTV, cartel de señales, apeadero, silbato, detención inmediata (cada una en versión normal y corta) |
